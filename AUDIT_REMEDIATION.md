## 3. Experiment Index & Evidence Synthesis (Stages 1–4)

### Stage 1: Exploratory Trials (Experiments 1–16)
- **Scope:** Cache eviction policies (Exp 1–6), continuous function optimization (Exp 7), 0/1 knapsack (Exp 8–11), traveling salesperson / graph coloring (Exp 12–16).
- **Condition:** Synthetic benchmarks (Zipf, uniform random). Uncontrolled prompt modifications, shared seeds, and AST mutations.
- **Evidence Verdict:** **Exploratory.** No generalizable heuristic discovery was demonstrated. High reported percentage gains reflected narrow tuning on specific synthetic distributions.

### Stage 2: Selection Mechanism Study (Graph Coloring & PFSP)
- **Scope:** 30 paired trials evaluating Arm D (Execution Selection) vs Arm B (Execution-Blind LLM Judge) vs Arm A (Random Draw) vs Arm C (Diversified Pool).
- **Findings:**
  - Graph Coloring: Arm D mean 1227.6 colors vs Arm B mean 700,371.4 colors ($p = 3.83 \times 10^{-6}$); Arm B crashed in 21/30 trials.
  - PFSP Scheduling: Arm D valid mean 1,072,414 vs Arm B valid mean 1,073,237 ($p = 8.61 \times 10^{-3}$); Arm B crashed in 10/30 trials.
- **Evidence Verdict:** **Supported.** Proved that execution filtering is necessary to select working heuristics from LLM candidate pools.
- **Limitation:** PFSP invalid penalty was set to 999,999, creating an inversion flaw against valid schedules (>1,000,000 makespan).

### Stage 3: Closed-Loop Feedback vs Independent Sampling (Graph Coloring)
- **Scope:** 30 paired trials (9,000 candidate slots, seeds 30301–30330) comparing Arm A (Independent Sampling) vs Arm C (Closed-Loop Execution Feedback).
- **Findings:**
  - Candidate Validity: Arm C yielded 89.7% valid code vs Arm A's 50.6% ($p = 1.22 \times 10^{-4}$).
  - Final Heuristic Quality: Arm A achieved 38,170 total colors across 200 hidden graphs (mean 1272.33) vs Arm C's 38,180 total colors (mean 1272.67). Paired difference: $\Delta = +0.33$ colors ($p = 0.9741$, 95% CI: $[-6.10, +6.70]$).
  - Runtime: Arm C heuristics ran in 5.30 ms/graph. As recorded in `closure_statistics.json:126`, the official closure benchmark ratio against DSATUR (0.34 ms/graph) is **15.5x** (5.30 / 0.34 = 15.58x, rounded to 15.5x). Recomputations on local hardware vary slightly between **14.5x and 15.5x** depending on machine load, but both conclusively confirm the AI heuristics run ~15x slower than DSATUR, thoroughly debunking the miscalculated 2,000x unit-mismatch claim.
- **Evidence Verdict:** **Decisively Refuted.** Feedback improves code compilation reliability but provides zero benefit in algorithmic search performance.

### Stage 4: Online 1D Bin Packing (Pilot 1)
- **Scope:** 3 pilot trials (seeds 40401–40403, 150 candidate slots) comparing Arm A (Independent Sampling) vs Arm C (Evolutionary Search) on development streams (`dev.json`). Hard budget enforcer ($15 cap, 300 request limit).
- **Findings:**
  - Financial & Request Containment: $3.96 spent, 276 requests executed, 0 budget overruns.
  - Candidate Accounting: Each trial initializes with 4 canonical baseline seeds: Best-Fit, Worst-Fit, First-Fit, and Almost-Worst-Fit (not Next-Fit). Including these 4 seeds/trial, reported validity was 10.0% (Arm A) and 24.0% (Arm C). **Excluding seeds, AI-only validity was 2.17% (1/46) in Arm A and 17.39% (24/138) in Arm C.**
  - Discovered Heuristics: In all 3 trials, both arms selected the canonical human Best-Fit seed (`cand-9ab4ff8e`, fitness 0.031433). Neither arm discovered a novel heuristic outperforming Best-Fit.
  - Gate 1 Evaluation: Gate 1 required development improvement $\bar{\Delta}_{\text{dev}} < -0.005$. Because $\bar{\Delta}_{\text{dev}} = 0.0000$, Gate 1 failed.
  - Protocol Compliance: Phase 2 confirmatory mode was correctly prevented from launching.
- **Evidence Verdict:** **Inconclusive / Halted at Gate 1.** Feasibility demonstrated; search efficacy failed gate. Phase 2 halted.
