## 1. Original Result

During initial discovery testing on the `cache_policy` problem, the engine reported:

- **Human Baseline (LFU):** `57.1944` fitness (overall miss rate % across train, test, and generalization sets)
- **Amaura Discovered Champion:** `56.9299` fitness
- **Reported Improvement:** `+0.46%` relative reduction in miss rate (an absolute drop of `0.2645` percentage points)
- **Discovered Code (`best_discovered_algorithm.py`):**

```python
def evict_score(key: int, recency: int, frequency: int, age: int, cache_size: int) -> float:
    # Discovered adaptive frequency-recency decay policy
    alpha = 1.402
    beta = 0.386
    return (float(frequency) ** alpha) / ((float(recency) + 0.91) ** beta)
```

## 6. LLM vs AST Mutator

We evaluated the relative contribution of each engine component:

- **Condition A (LFU Baseline):** `57.1944` fitness.
- **Condition B (Autonomous AST Mutator alone):** `56.9299` fitness (`+0.46%` improvement).
- **Condition C (LLM-Driven Evolution):** Not engaged due to API quota exhaustion.

### Finding:
**The entire improvement was generated by the AST mutator, not an LLM.**  
The structural innovation—combining frequency with a recency decay denominator—was embedded in the human-authored AST mutation template `_inject_tight_fit_threshold` in `amaura/engine/generator.py`:
```python
code = (
    "def evict_score(key: int, recency: int, frequency: int, age: int, cache_size: int) -> float:\n"
    f"    alpha = {round(self.rng.uniform(0.6, 1.4), 2)}\n"
    f"    beta = {round(self.rng.uniform(0.3, 0.9), 2)}\n"
    f"    return (float(frequency) ** alpha) / ((float(recency) + 1.0) ** beta)\n"
)
```
The evolutionary search merely optimized the numeric constants ($\alpha=1.402, \beta=0.386$). The AI did not invent this mathematical relationship from first principles.

## 8. Ablation Study

We systematically ablated the components of the formula to determine whether the exact discovered parameters ($\alpha=1.402, \beta=0.386, \text{offset}=0.91$) are critical:

| Formula Variant | Description | Overall Miss Rate | Test Miss Rate |
| :--- | :--- | :---: | :---: |
| **`f^1.402 / (r + 0.91)^0.386`** | **Discovered Champion** | **56.9299%** | **39.3920%** |
| `f^1.402 / (r^0.386)` | No +0.91 offset ($r$ clamped) | 56.9480% | 39.4133% |
| `f^1.4 / (r + 1.0)^0.4` | Rounded exponents ($\alpha=1.4, \beta=0.4$) | 56.9728% | 39.4480% |
| `f^1.0 / (r + 1.0)^1.0` | Linear ratio ($f / (r+1)$) | 58.7699% | 41.5120% |
| `f` | Pure LFU | 57.1944% | 40.0640% |
| `-r` | Pure LRU | 61.8440% | 46.5333% |
| `1 / (r + 1.0)^0.386` | Pure recency decay (no frequency) | 61.8440% | 46.5333% |
| `f^1.402` | Pure frequency exponent (monotonic) | 57.1944% | 40.0640% |

### Ablation Findings:
1. **The exact precision does not matter:** Rounding $1.402 \to 1.4$ and $0.386 \to 0.4$ produces virtually identical performance ($56.97\%$ vs $56.93\%$).
2. **The offset does not matter:** Removing the $0.91$ offset changes performance by less than $0.02\%$.
3. **The power ratio is critical:** A linear ratio $f / (r+1)$ fails ($58.77\%$). The policy requires a **super-linear frequency weight** ($\alpha \approx 1.4$) paired with **sub-linear recency decay** ($\beta \approx 0.4$) to avoid premature eviction of frequently accessed items.

## 10. Statistical Significance & Final Conclusion

### Statistical Significance Test (100 Independent Stochastic Trials)

We tested the champion against LFU across 100 randomly generated independent workloads (1,000 steps each):

- **Mean Miss Delta ($\text{Miss}_{\text{LFU}} - \text{Miss}_{\text{Amaura}}$):** `+0.0450%`
- **Sample Standard Deviation:** `0.7496%`
- **Standard Error of the Mean:** `0.0750%`
- **95% Confidence Interval:** `[-0.1019%, +0.1919%]`
- **Paired $t$-test statistic:** $t = 0.6003$, **$p = 0.5497$**
- **Wilcoxon Signed-Rank Test:** $W = 2056.0$, **$p = 0.3054$**

### Statistical Interpretation:
The $95\%$ confidence interval `[-0.10%, +0.19%]` **crosses zero**, and the paired $t$-test $p$-value is **$0.55 \gg 0.05$**. Across diverse, independent stochastic traces, the measured difference between Amaura and LFU cannot be distinguished from random noise at standard scientific significance thresholds.

---

## Final Conclusion

### **INCONCLUSIVE**

### Rationale:
1. **The improvement is real on specific workloads, but not statistically significant overall:**  
   On Zipfian workloads, combining frequency with recency decay genuinely reduces miss rates by $0.5\% - 1.6\%$. However, across 100 independent workload trials, the mean improvement is tiny ($+0.045\%$), the $95\%$ confidence interval crosses zero ($[-0.10\%, +0.19\%]$), and the $p$-value is $0.55$.
2. **Two out of five discovery runs failed to beat LFU:**  
   The discovery engine achieved a win rate of only $60\%$, with a mean improvement of only $0.13\%$ across seeds.
3. **No AI Discovery Occurred:**  
   The formula was not synthesized by an LLM reasoning over algorithmic tradeoffs. It was a pre-coded heuristic template inside the AST generator whose numeric coefficients were adjusted by local stochastic perturbation.

This result represents **local parameter optimization on a human-authored heuristic template**, not an autonomous discovery of a novel algorithm.
